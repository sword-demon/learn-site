# 功能规格：学员优惠券领取与下单抵扣

**功能分支**：`009-learner-coupons`

**创建日期**：2026-09-01

**状态**：草稿

**输入**：用户描述："新增优惠券功能，可以针对某个分类，也可以针对具体课程，也可以无门槛，需要有使用上限，可以有满减，以及过期时间；对应的前台领取的地方需要新增；以及后台发放；前台下订单的时候也需要添加可选优惠券"

## 用户场景与测试（必填）

### 用户故事 1：管理员创建并发放优惠券（优先级：P1）

具备优惠券管理权限的管理员在管理端创建优惠券活动，配置名称、适用范围（指定分类、指定课程或无门槛）、满减规则（满多少减多少）、领取或发放有效期、以及使用上限（全站总次数与每位学员可用次数）。管理员可将优惠券设为「学员自助领取」或「仅后台定向发放」。保存后，符合条件的学员可在学习端领取，或由管理员指定学员发放到其账户。

**优先级原因**：没有可配置的优惠券模板与发放能力，前台领取与下单抵扣均无从谈起。

**独立测试**：管理员创建一张「满 99 减 20、仅限某分类、每人限用 1 次、总量 100 张」的优惠券并设为可领取；另一张「无门槛减 10、仅指定课程、后台定向发放」；验证配置保存、列表展示与发放记录准确。

**验收场景**：

1. **前提** 管理员填写完整优惠券信息且满减金额小于等于满减门槛对应的可抵扣上限，**当** 保存，**则** 优惠券创建成功并在管理端列表可见。
2. **前提** 优惠券适用范围为「指定分类」，**当** 管理员选择一至多个已启用分类，**则** 仅购买该分类下收费课程时学员可选用此券。
3. **前提** 优惠券适用范围为「指定课程」，**当** 管理员选择一门或多门已发布收费课程，**则** 仅购买所列课程时学员可选用此券。
4. **前提** 优惠券为「无门槛」类型，**当** 保存，**则** 任意收费课程订单在满足满减金额规则时均可尝试使用（满减门槛为 0 时表示无最低消费要求）。
5. **前提** 优惠券设为「学员自助领取」且仍在领取有效期内，**当** 学员在学习端领取中心领取，**则** 该券进入学员「我的优惠券」且领取数计入全站上限。
6. **前提** 管理员对指定学员执行定向发放，**当** 发放成功，**则** 该学员「我的优惠券」中出现该券，无需自行领取。
7. **前提** 全站领取/使用已达上限或优惠券已过期，**当** 学员尝试领取或使用，**则** 操作被拒绝并给出明确原因。
8. **前提** 管理员无优惠券管理权限，**当** 访问创建、发放或列表，**则** 操作被拒绝且不泄露优惠券配置细节。

### 用户故事 2：学员在学习端领取与查看优惠券（优先级：P1）

学习端新增「优惠券」入口（如学员中心或独立分页）。已登录学员可浏览当前可领取的优惠券，查看面值、满减规则、适用范围、有效期与剩余名额；一键领取后加入「我的优惠券」。学员可分页查看已领取券的状态：未使用、已使用、已过期；每条展示适用说明与过期时间。

**优先级原因**：用户明确要求前台新增领取入口，是优惠券触达学员的主路径。

**独立测试**：预置 3 张可领取券与 2 张已领取券，学员打开领取中心与我的优惠券页，验证展示、领取成功、重复领取拒绝、过期与已领完提示。

**验收场景**：

1. **前提** 存在可领取且未过期的优惠券，**当** 学员打开领取中心，**则** 展示券名称、满减规则、适用范围摘要、有效期与剩余可领数量（若配置了总量上限）。
2. **前提** 学员点击领取且未达每人限领次数，**当** 领取成功，**则** 券出现在「我的优惠券」且状态为未使用。
3. **前提** 学员已达该券每人限领次数，**当** 再次领取，**则** 被拒绝并提示已达上限。
4. **前提** 学员未登录，**当** 访问领取中心或我的优惠券，**则** 引导至学员登录页。
5. **前提** 学员持有未使用优惠券，**当** 在「我的优惠券」查看，**则** 可按状态筛选并看到过期倒计时或已过期标识。
6. **前提** 优惠券仅支持后台定向发放、未开放领取，**当** 学员浏览领取中心，**则** 不展示该券（除非已被发放到该学员账户）。

### 用户故事 3：学员下单时选用优惠券（优先级：P1）

学员购买收费课程进入订单确认页时，系统基于课程与当时**当前价格**（含限时优惠价，若有）计算可用优惠券列表。学员可选择一个可用券或选择不使用；价格明细展示标准价、限时优惠（若有）、优惠券抵扣与应付金额。提交订单时服务端再次校验券的有效性、适用范围、满减门槛与使用上限；校验通过后订单快照记录所用优惠券与抵扣金额，实付金额不得低于零。支付成功后标记该券实例为已使用；支付失败或取消时释放占用，券仍可使用（若未过期且未达次数上限）。

**优先级原因**：下单抵扣是优惠券的核心价值闭环，直接关联购买转化。

**独立测试**：学员对适用课程持有「满 50 减 15」券，在确认页选用后应付金额正确；切换不适用课程时该券不可选；支付成功后券变已使用，重复下单不可再用。

**验收场景**：

1. **前提** 学员对当前课程持有一张适用且未过期的优惠券，**当** 打开订单确认页，**则** 在可选优惠券列表中展示该券及抵扣后应付预览。
2. **前提** 订单**当前价格**未达到优惠券满减门槛，**当** 学员查看可选券，**则** 该券不可选或标注「未满 ¥X 可用」类说明。
3. **前提** 学员选择一张优惠券，**当** 提交创建订单，**则** 订单快照包含标准价、限时优惠价（若有）、优惠券抵扣额、实付价与所用券标识；实付价 = 当前价格 − 抵扣额，且 ≥ 0。
4. **前提** 学员不选择优惠券，**当** 提交订单，**则** 行为与现有购买流程一致，实付价等于当前价格。
5. **前提** 学员在确认页选用优惠券后支付成功，**当** 订单完成，**则** 该券实例标记为已使用，且同一实例不可再次用于其他订单。
6. **前提** 订单待支付期间优惠券过期或被管理员停用，**当** 学员继续支付，**则** 支付前须重新确认价格或提示券已失效并要求重新下单。
7. **前提** 学员对免费课程发起学习，**当** 进入购买流程，**则** 不出现优惠券选择（免费课程不适用优惠券）。
8. **前提** 学员已持有该课程访问权，**当** 尝试再次购买，**则** 不得创建新订单或使用优惠券重复购买同一课程。

### 用户故事 4：管理员查询优惠券与使用记录（优先级：P2）

管理员在管理端查看优惠券列表，支持按状态（未开始、进行中、已结束、已停用）、适用范围类型筛选与分页。可查看单券详情、领取/发放数量、已使用数量、剩余额度。可查看使用记录列表（学员标识脱敏、关联课程、订单、抵扣金额、使用时间）。管理员可提前停用优惠券；停用后不可新领取，已领取未使用的券在下单时视为不可用。

**优先级原因**：运营需要掌握发放效果与异常核销，支撑活动复盘与风控。

**独立测试**：一张券被 10 名学员领取、3 名使用，管理员列表与详情数字一致；停用后新领取失败、未支付订单重新校验失败。

**验收场景**：

1. **前提** 系统中存在多张优惠券，**当** 管理员打开列表，**则** 展示名称、类型、满减规则、有效期、状态与已用/总量摘要。
2. **前提** 管理员打开某券详情，**当** 查看，**则** 展示完整配置、领取/发放与使用统计。
3. **前提** 管理员停用进行中的优惠券，**当** 保存，**则** 学员不可新领取；已持有未使用券在下单校验时被拒绝。
4. **前提** 管理员查看使用记录，**当** 按优惠券或时间筛选，**则** 结果与订单数据一致且不泄露无关学员隐私。

---

### 边界场景

- 同一订单仅允许选用一张优惠券；不可叠加多张券，也不与第二重手工输入码叠加。
- 优惠券抵扣在限时优惠价之后计算：应付金额以确认订单瞬间的**当前价格**为基数，再减去满减抵扣，不得低于零。
- 满减规则中「满 X 减 Y」须满足 Y ≤ X（无门槛时 X 为 0，Y 为面值）；配置不合法时保存被拒绝。
- 领取有效期与使用有效期可分别配置：过期未领取的公开券不可再领；已领取券在使用有效期内仍可使用（若单独配置使用截止），否则与领取截止或活动截止对齐（见假设）。
- 并发领取最后一张名额时，仅一名学员成功，其余提示已领完。
- 待支付订单占用优惠券：创建订单时锁定所选券实例，取消或超时未支付后释放（见假设）。
- 分类适用范围：课程所属分类为分类树中任一匹配节点即可（含子分类课程，若课程挂于子分类）。
- 管理员删除或下架课程后，仅针对该课程的优惠券在下单时自动不可用，管理端展示关联失效提示。
- 学员账户停用后不可领取或使用优惠券；历史使用记录仍可供管理员审计查询。
- 管理端与学习端鉴权隔离；各自受保护接口仅接受对应端有效令牌。
- 订单快照不可变：支付成功后即使管理员修改优惠券配置，历史订单抵扣记录不变。

## 需求（必填）

### 功能需求

- **FR-001**：系统必须支持创建优惠券，包含名称、满减规则（满额门槛与减免金额）、适用范围（指定分类 / 指定课程 / 无门槛）、领取方式（公开领取 / 仅后台发放）、领取有效期、使用有效期（可与领取期相同或单独配置）、全站总使用或领取上限、每位学员限领次数与限用次数。
- **FR-002**：适用范围为「指定分类」时，必须选择一个或多个已启用分类；仅当购买订单对应课程属于所选分类（含其子分类挂载）时该券可用。
- **FR-003**：适用范围为「指定课程」时，必须选择一门或多门已发布收费课程；仅购买所列课程时该券可用。
- **FR-004**：「无门槛」优惠券表示不限制课程分类或具体课程，但仍须满足满减金额规则与收费课程前提。
- **FR-005**：学习端必须提供优惠券领取入口与「我的优惠券」分页列表，展示可领取与已持有券的状态、规则摘要与有效期。
- **FR-006**：学员必须能够一键领取公开券；领取须校验每人限领、全站剩余名额与领取有效期。
- **FR-007**：管理员必须能够将优惠券定向发放给一名或多名学员；发放须记入发放记录并受全站上限约束。
- **FR-008**：管理端必须提供优惠券的创建、编辑（未开始或进行中有限字段）、停用与列表查询能力；关键变更须记入审计日志。
- **FR-009**：订单确认页必须展示当前课程可用优惠券列表，学员可选择一张或不用；价格明细须展示抵扣前价、限时优惠（若有）、优惠券抵扣与应付金额。
- **FR-010**：创建订单时必须服务端校验优惠券：归属当前学员、未使用、未过期、适用范围匹配、满减门槛满足、未超每人限用、券未被停用；校验失败须拒绝下单并返回明确原因。
- **FR-011**：购买订单快照必须新增优惠券相关字段：所用券标识、抵扣金额；实付金额不可为负。
- **FR-012**：支付成功后必须将对应优惠券实例标记为已使用，并与订单唯一关联；支付失败、取消或待支付超时须释放锁定（见假设）。
- **FR-013**：免费课程、已拥有访问权的重复购买不得使用优惠券。
- **FR-014**：管理端必须提供优惠券使用记录查询，关联学员（脱敏）、课程、订单、抵扣金额与时间。
- **FR-015**：首版不提供：优惠券叠加、退款退券、会员专享券、随机面额、分享裂变领券、地图/套餐通用券、导出报表、学员转让优惠券。

### 关键实体

- **优惠券模板（Coupon Campaign）**：运营配置的一次优惠活动，定义满减规则、适用范围、有效期、上限与领取方式；可被多名学员持有实例。
- **优惠券实例（Learner Coupon）**：学员持有的一张具体优惠券，状态为未使用、已使用、已过期或已失效；关联模板与学员，可关联至多一笔成功支付的订单。
- **满减规则（Threshold Discount Rule）**：「满 minimum_amount 减 discount_amount」；minimum_amount 为 0 表示无最低消费门槛。
- **适用范围（Coupon Scope）**：枚举为指定分类、指定课程、无门槛；决定下单时是否可候选。
- **领取记录（Coupon Claim Record）**：学员自助领取或管理员定向发放的记录，用于统计限领与名额。
- **使用记录（Coupon Redemption）**：优惠券在订单中成功抵扣的记录，与购买订单一对一绑定。

## 成功标准（必填）

### 可衡量结果

- **SC-001**：具备权限的管理员可在 5 分钟内完成一张优惠券的创建并使其对学习端可见（常规网络与数据量）。
- **SC-002**：学员从打开领取中心到成功领取一张公开券，90% 的场景在 30 秒内完成。
- **SC-003**：适用券在订单确认页的抵扣金额计算准确率 100%（与规则及当前价格一致）。
- **SC-004**：不适用券被错误核销的比例为 0%（含跨分类、跨课程、过期、超限场景）。
- **SC-005**：支付成功后优惠券状态更新为已使用的成功率 ≥ 99.9%。
- **SC-006**：全站名额耗尽或每人限领触顶时，学员收到明确拒绝提示的比例 100%，不产生超发。
- **SC-007**：管理员在优惠券详情页看到的领取数、使用数与订单数据一致率 100%。
- **SC-008**：可用性测试中，至少 80% 的学员能在无额外培训下完成「领取 → 下单选券 → 支付」；至少 80% 的管理员能完成「创建 → 发放 → 查看使用记录」。

## 假设

- 「优惠券」为本期新增的促销能力，与课程自带的「限时优惠价」并存；抵扣基数为下单确认瞬间的**当前价格**（已含限时优惠），二者不叠加二次折让。
- 每笔购买订单仅对应一门收费课程，与现有购买订单模型一致；一张优惠券实例最多成功用于一笔订单。
- 领取有效期指学员可领取或可被发放的时间窗；使用有效期指已持有券可参与下单的时间窗。若未单独配置使用有效期，则与领取有效期结束时间相同。
- 待支付订单创建时锁定所选优惠券实例；订单取消、支付失败或超过待支付时限（与现有订单超时策略一致）后释放锁定，学员可再次使用（若仍有效）。
- 「使用上限」同时包含全站维度（总可领取或总可使用次数，创建时二选一或同时配置，默认总可使用次数）与每位学员限领、限用次数；具体默认值为全站 10,000 次、每人限领 1 张、限用 1 次，管理员可调整。
- 货币与金额精度与现有购买订单一致（人民币、两位小数）；满减金额不得超过订单**当前价格**。
- 优惠券管理权限以单一权限码控制创建、发放、停用与记录查询；更细粒度角色拆分不在首版范围。
- 学习端领取入口位于学员中心导航下「优惠券」子页，并提供从订单确认页跳转查看可用券的链接。
- 停用优惠券不删除历史领取与使用记录；已支付订单不受影响。
- 首版不支持学员输入任意字符串兑换码领取，仅支持系统生成的券与公开领取列表；兑换码形态留作后续迭代。
