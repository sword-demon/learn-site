# Quickstart 验证指南：管理后台标签页与导航

目标：在实现完成后，验证 [spec.md](./spec.md) 四条用户故事与 [contracts/navigation-ui.md](./contracts/navigation-ui.md) 行为契约。实现细节见后续 `tasks.md`（`$speckit-tasks` 生成）。

## 前置

- 仓库已启动：`docker compose up -d` 或本地 `pnpm --filter @learn-site/admin dev`
- 管理端可访问（默认 `${ADMIN_PORT:-8081}`）
- 具备超级管理员或 `dashboard.view` + 若干模块权限的测试账号

## 人工验收剧本

### 1. 默认工作台与打开标签（US1）

1. 登录管理端，进入主布局。
2. 确认标签栏可见，且仅有「工作台」标签（固定，无关闭按钮或关闭无效）。
3. 侧栏点击「课程管理」→ 新增「课程管理」标签并激活，内容区为课程列表。
4. 点击「订单管理」→ 再增一标签。
5. 再次点击侧栏「课程管理」→ 标签数量不变，激活切回「课程管理」。
6. 点击「订单管理」标签 → 内容区与 URL 同步为订单列表。

**通过**：步骤 2–6 与 spec 验收场景一致；URL 与标签始终一致。

### 2. 面包屑（US2）

1. 进入「组织管理 → 员工管理」。
2. 面包屑显示「组织管理 / 员工管理」（或等效层级文案）。
3. 进入「课程管理」→「新建课程」。
4. 面包屑包含课程模块上级与「新建课程」；与标签标题一致。
5. 点击面包屑中的「课程管理」（若可点击）→ 回到课程列表。

**通过**：无空白面包屑；层级与菜单/标题一致。

### 3. 关闭标签（US3）

1. 打开工作台 + 课程管理 + 订单管理 + 学员账号（至少 3 个业务标签）。
2. 激活「订单管理」，执行「关闭当前」→ 订单标签消失，激活相邻标签。
3. 激活「学员账号」，执行「关闭其他」→ 仅保留工作台 + 学员账号。
4. 执行「关闭全部」→ 仅保留工作台并激活。
5. 尝试关闭「工作台」→ 无效。

**通过**：工作台始终保留；无空白主内容区。

### 4. 加载进度条（US4）

1. 在 layout 内从工作台切换到课程管理，观察页面顶部细进度条出现并完成。
2. 通过标签切换多个页面，每次均有进度反馈。
3. 在课程列表页仅使用表格筛选（不改变路由）→ 进度条不出现。
4. 退出登录到登录页 → 登录页无管理端进度条。

**通过**：进度条不卡住；非路由操作不触发。

### 5. 边界场景

| 场景 | 操作 | 预期 |
|---|---|---|
| 深层 URL | 地址栏直接打开 `/courses/new` | 创建对应标签与面包屑 |
| 浏览器后退 | 打开多页后点后退 | 标签激活与历史一致 |
| 登出 | 多标签状态下退出 | 下次登录仅工作台 |
| 动态实例 | 打开两门不同课程的编辑页 | 两个独立标签，标题可区分 |
| 无权限 | 访问无权限模块 URL | 落点页正确，无多余脏标签 |
